## ✨ Что это

Набор BAT-файлов для Windows. **zapret (winws + WinDivert)** помогает подключиться к
**Cloudflare WARP (MASQUE)**, а WARP пускает через себя трафик любой игры и любого лаунчера.

Основа — [Flowseal/zapret-discord-youtube](https://github.com/Flowseal/zapret-discord-youtube)
**1.10.4** (профили, фейки, списки). Адаптацию под WARP; эту сборку
развивает и сопровождает **[PsyGioX](https://github.com/PsyGioX)** —
[PsyGioX/zapret-warp-for-games](https://github.com/PsyGioX/zapret-warp-for-games).

> [!NOTE]
> Неофициальный пользовательский проект, не связан с Cloudflare, Valve, издателями игр
> и т. д. Работоспособность зависит от провайдера и региона.

## 🚀 Быстрый старт

1. **Распакуйте** архив целиком в простой локальный путь, например `C:\zapret-warp`.
2. **`1 - INSTALL Cloudflare WARP.bat`** → установите клиент, выберите «Приватный просмотр»,
   WARP не включайте.
3. **`2 - START Games via WARP.bat`** (от администратора) → выберите профиль и режим.
4. Дождитесь `Connected`, запустите игру или лаунчер сами.
5. После игры вернитесь в чёрное окно и нажмите **Enter** — всё остановится.

### Режимы захвата

| № | Режим | Что перехватывается | Когда выбирать |
| :-: | --- | --- | --- |
| **1** | ⚡ Низкая задержка | только порты WARP | **по умолчанию, рекомендуется** |
| **2** | 🛡️ Совместимость | все порты 1024-65535, TCP+UDP | если режим 1 не подключился |
| **3** | 🎯 Свои порты | то, что вы укажете | если игре нужны особые порты |

### Файлы набора

| Файл | Назначение |
| --- | --- |
| `1 - INSTALL Cloudflare WARP.bat` | Открывает официальный установщик Cloudflare WARP |
| `2 - START Games via WARP.bat` | Профиль + режим → zapret → MASQUE → WARP → замер качества |
| `3 - STOP WARP and zapret.bat` | Аварийная остановка, если окно запуска закрыли крестиком |
| `4 - CHECK ping and packet loss.bat` | Пинг, джиттер и потери до любого хоста (например, сервера игры) |
| `5 - FULL UNINSTALL zapret-warp.bat` | Полное удаление: службы, драйвер, реестр, следы; по желанию WARP и папка |
| `service.bat` | Меню Flowseal: диагностика, тесты, смена фейков, Game Filter |

## 📈 Что нового по сравнению с прежней сборкой

| Было | Стало |
| --- | --- |
| База Flowseal 1.9.9d | База **1.10.4** (профили ALT13, EXP, ACTIVE-фейки, настраиваемые порты Game Filter) |
| Game Filter всегда **TCP+UDP 1024-65535** — через winws шёл весь трафик ПК | Режим **«Низкая задержка»** (по умолчанию): перехват только портов WARP |
| Фиксированные 10 с ожидания WARP | Ожидание статуса `Connected` до 30 с, старт сразу при подключении |
| Профиль выбирался заново каждый раз | Запоминаются профиль, режим и свои порты; Enter = как в прошлый раз |
| Нет отката при неудаче | Если WARP не подключился — предложение перезапуска в режиме совместимости |
| winws с обычным приоритетом | winws получает приоритет **High** (меньше очередь пакетов) |
| Нет замера качества | `4 - CHECK` — задержка, джиттер, потери |

<details>
<summary><b>⏱️ Почему это снижает задержку</b></summary>

<br>

С включённым WARP весь игровой трафик упакован в один туннель на `162.159.197.0/24`,
**UDP 443** (запасные UDP-порты: 500, 1701, 4443, 4500, 8095, 8443).
Прежняя настройка заставляла WinDivert перехватывать *все* порты 1024-65535, то есть
гнать через пользовательский процесс загрузки Steam, торренты, голосовой чат и т. д.
Режим «Низкая задержка» перехватывает только то, что нужно для подключения WARP.

> [!IMPORTANT]
> **Нулевые потери пакетов не гарантирует ни zapret, ни WARP** — итоговый пинг определяется
> маршрутом провайдер → Cloudflare → сервер игры. Сборка убирает собственные накладные
> расходы и даёт инструмент замера, чтобы подобрать лучший профиль под вашу сеть.

</details>

## 🗑️ Полное удаление

`5 - FULL UNINSTALL zapret-warp.bat` (от администратора) предлагает два режима: очистить систему
и оставить папку либо очистить и удалить папку целиком.

- отключает Cloudflare WARP и закрывает его окно, останавливает `winws.exe`;
- удаляет службы `zapret`, `WinDivert`, `WinDivert14` и их ключи реестра;
- чистит временные файлы и исключения Microsoft Defender, указывающие на эту папку;
- по вашему выбору возвращает TCP timestamps к значению Windows по умолчанию (zapret их включает);
- по вашему выбору удаляет сам Cloudflare WARP (тихо, через MSI);
  ручной проверки — чужие строки сам не правит;
- проверяет результат и, если что-то удалилось не полностью, просит перезагрузку.

<details>
<summary><b>🔒 Как защищено удаление папки</b></summary>

<br>

Папка удаляется только после ввода `DELETE` и только если это действительно сборка zapret-warp
(проверяются `service.bat`, `general.bat`, `bin\winws.exe`, `bin\WinDivert64.sys`). Диски, профиль
пользователя, Рабочий стол, Документы, Загрузки и системные папки защищены. Удаление выполняется
отдельным процессом уже после закрытия окна. Регистрация устройства в аккаунте Cloudflare не
затрагивается (для её удаления потребовалась бы сеть).

</details>

## 🎯 Как подобрать лучший профиль

1. Запустите профиль, дождитесь `Connected`.
2. Запустите `4 - CHECK`, укажите IP игрового сервера, 50 проб.
3. Ищите **0 % потерь** и малый джиттер; если хуже — остановите (Enter) и повторите с другим
   профилем или режимом.

## 🔐 Автономность и аудит

Вся работа выполняется локально. Из интернета нужны только установщик и сам Cloudflare WARP.

- Удалён код, ходивший в GitHub: проверка версий, загрузка `ipset`, правка `hosts` из меню
  (пункты 8–10 `service.bat` показывают заглушку «offline»).
- В `utils/test zapret.ps1` отключена загрузка внешнего набора DPI-проверок.
- Актуальный список IP (`lists/ipset-all.txt`) поставляется внутри архива; для обновления
  замените файл вручную.
- Удалены `bin/.sentry-native` (служебные дампы), `.github`, `.service`.
- Лаунчер и `warp-quality.ps1` ничего не скачивают и не отправляют; `warp-quality.ps1` использует
  только ICMP-ping.
- `hosts` меняется **только** скриптом 6 и только по вашей команде; перед первым изменением
  делается копия. Скрипт обращается лишь к IP, который вы сами ввели.
- Список файлов и контрольные суммы: `SHA256SUMS.txt`.

## 🩺 Если не работает

- Перезапустите и выберите другой профиль `general*`.
- Выберите режим 2 (Совместимость) — лаунчер предложит это сам, если WARP не подключился.
- Проверьте антивирус: он не должен блокировать `winws.exe` и WinDivert (часто помечаются как
  RiskTool/PUA). Проверяйте источник архива и SHA-256.
- Не запускайте из ZIP и из путей с кириллицей / OneDrive.
- `service.bat` → «Run Diagnostics».
